# Drum Machine

A web-based interactive drum machine built with vanilla JavaScript, HTML5, and CSS3. This application allows users to trigger various percussion sounds either by clicking on the drum pads or by using corresponding keyboard keys.

## Features

- **Interactive Pad Bank**: 9 distinct drum pads styled with custom CSS transitions.
- **Dual Input Support**: Triggers audio playback via mouse clicks and keyboard key strokes (`Q`, `W`, `E`, `A`, `S`, `D`, `Z`, `X`, `C`).
- **Dynamic Display**: Automatically updates the status text area to show the description of the currently played audio sample.
- **Audio Management**: Built using HTML5 `<audio>` elements and the HTMLMediaElement API for reliable playback.

## Technologies Used

- **HTML5**: Semantic structure and media integration.
- **CSS3**: Flexbox, CSS Grid, and custom styling for a modern dark-themed UI.
- **JavaScript (ES6+)**: Event listeners, DOM manipulation, and audio control logic.
